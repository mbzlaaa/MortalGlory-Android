# Scenes 目录

此目录用于存放 Unity 场景文件（`.unity`）。

> ⚠️ 场景是**二进制/YAML 混合格式**，无法手工文本创建，必须由 Unity 编辑器
> 生成或从原工程导出。当前阶段（骨架）此目录为空占位。

原游戏场景文件（来自 `MortalGlory_Data`）：
- `level0`
- `level1`
- `level2`

场景重建是本次移植的**唯一真正瓶颈**（⭐⭐⭐⭐）。计划：
1. 用 AssetStudio 导出场景层级结构（GameObject 树 + 组件）
2. 编写脚本/工具将层级还原为 Unity 场景
3. 或退而求其次：新建空白场景 + 运行时动态构建

此文件仅作占位说明，最终删除。
